# What Is the `whoami` Command?

The `whoami` command displays the username of the currently logged-in user.

Example:

```bash
whoami
```

Output:

```text
student
```

If you become the root user:

```bash
sudo -i
```

Then run:

```bash
whoami
```

Output:

```text
root
```

The output changes depending on who is currently using the shell.

# Understanding the Script

## Line 1

```bash
#!/bin/bash
```

Specifies that the script should run using the Bash shell.

---

## Line 2

```bash
echo "Hello $(whoami)!"
```

Let's break it down.

### Step 1

```bash
whoami
```

Produces:

```text
student
```

### Step 2

Command substitution:

```bash
$(whoami)
```

Stores the output temporarily.

### Step 3

The command becomes:

```bash
echo "Hello student!"
```

Final output:

```text
Hello student!
```

---

# How Command Substitution Works

```text
whoami
   │
   ▼
student
   │
   ▼
$(whoami)
   │
   ▼
echo "Hello student!"
```

# LAB 5 – Store the Username in a Variable

Instead of placing the command directly inside `echo`, create a variable.

Edit:

```bash
nano hello.sh
```

Replace the script with:

```bash
#!/bin/bash

CURRENT_USER=$(whoami)

echo "Hello $CURRENT_USER!"
```

Run:

```bash
./hello.sh
```

Output:

```text
Hello student!
```

Both methods work.

---

# Direct Method vs Variable Method

## Direct Method

```bash
echo "Hello $(whoami)!"
```

Simple and useful for one-time use.

---

## Variable Method

```bash
CURRENT_USER=$(whoami)

echo "Hello $CURRENT_USER!"
```

Better when the username will be used multiple times.

# 🔧 Troubleshooting

## Problem 1 – Script Prints Nothing

Check that the script contains:

```bash
echo "Hello $(whoami)"
```

and not:

```bash
echo "Hello $(who am i)"
```

The correct command is:

```bash
whoami
```

---

## Problem 2 – Permission Denied

Make the script executable.

```bash
chmod u+x hello.sh
```

---

## Problem 3 – Script Not Found

Run:

```bash
pwd
```

Verify that you are inside the directory containing `hello.sh`.

List the files:

```bash
ls
```

---

## Problem 4 – Username Does Not Change

Run:

```bash
whoami
```

If the command still displays the same username, you are still logged in as that user.

Switch users (if permitted):

```bash
sudo -i
```

or

```bash
su - username
```

Then test again.
