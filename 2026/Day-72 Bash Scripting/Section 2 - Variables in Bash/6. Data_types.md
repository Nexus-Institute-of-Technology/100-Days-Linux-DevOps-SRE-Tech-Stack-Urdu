# What is a Data Type?

A data type describes the kind of information stored inside a variable.

Examples:

| Data Type | Example |
|------------|---------|
| Integer | 25 |
| Float | 3.14 |
| Character | A |
| String | Linux |
| Boolean | true |

Programming languages usually treat each of these differently.

---

# Does Bash Have Data Types?

The simple answer is:

**No.**

Bash does **not** have traditional data types.

Bash is considered an **untyped scripting language**.

This means:

- Variables do not have declared types.
- The same variable can store different kinds of values.
- Bash does not distinguish between integers, strings, characters, or floating-point values the way languages such as Java or C++ do.

---

# Think of Bash as "Data Type Blind"

Imagine a person who is color blind.

They cannot distinguish between certain colors.

Similarly, Bash is:

```text
Data Type Blind
```

It does not distinguish between:

- Numbers
- Characters
- Strings
- Decimal values

To Bash, they are simply values stored in variables.

# Variable Reassignment

Variables can be reassigned any time.

Example:

```bash
city=Houston
```

Later:

```bash
city=Dallas
```

Later again:

```bash
city=Austin
```

Each assignment replaces the previous value.

---

# How Variables Work

```text
Variable

age
 │
 ▼

24

↓

27

↓

99
```

The variable name remains the same.

Only the value changes.

---

# Bash vs Programming Languages

Traditional Programming Language:

```java
int age = 24;
```

```python
age = 24
```

Bash:

```bash
age=24
```

Notice:

There is no keyword like:

```text
int
```

or

```text
float
```

or

```text
string
```

---

# Why?

Because Bash is:

```text
Untyped
```

Variables simply store values.
