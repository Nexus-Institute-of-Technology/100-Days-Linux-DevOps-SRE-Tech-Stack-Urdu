# Background

Variables are one of the most important concepts in Bash scripting.

Without variables, every script would always produce the same output.

Variables allow scripts to:

- Store information
- Reuse information
- Accept user input
- Produce different results every time the script runs

Variables make Bash scripts **dynamic** instead of **static**.

---

# What is a Variable?

A variable is simply a **storage location** that holds information.

Think of it like a storage box.

You can place different things inside the same storage box.

Examples:

- Books
- Clothes
- Toys
- Food
- Documents

Similarly, a Bash variable can store different values.

Example:

```text
Storage Box
    │
    ▼
+----------------+
|     NAME       |
+----------------+
| Ahmed          |
+----------------+
```

Later, the same variable can store:

```text
Jessica
```

or

```text
Sheila
```

or

```text
Darlene
```

The variable name stays the same, but its value changes.

---

# Why Do We Need Variables?

Without variables:

```bash
echo "Hello Ahmed"
```

Every user sees:

```text
Hello Ahmed
```

This is called a **static** script.

---

With variables:

```bash
echo "Hello $name"
```

Each user sees their own name.

Example:

User enters:

```text
Jessica
```

Output:

```text
Hello Jessica
```

Another user enters:

```text
David
```

Output:

```text
Hello David
```

Now the script is **dynamic**.

# Understanding the Script

## Line 1

```bash
#!/bin/bash
```

Tells Linux to execute the script using Bash.

---

## Line 2

```bash
echo "What's your name, stranger?"
```

Displays a message on the screen.

Output:

```text
What's your name, stranger?
```

---

## Line 3

```bash
read name
```

The **read** command waits for keyboard input.

Whatever the user types is stored inside the variable named:

```text
name
```

Example:

User types:

```text
Jessica
```

Now the variable contains:

```text
name = Jessica
```

---

## Line 4

```bash
echo "Hello $name"
```

Displays:

```text
Hello Jessica
```

The dollar sign (`$`) tells Bash:

> "Use the value stored inside the variable."

This is called **variable expansion**.

---

# Variable Expansion

Suppose:

```bash
name="Ahmed"
```

Then:

```bash
echo $name
```

Produces:

```text
Ahmed
```

Without the dollar sign:

```bash
echo name
```

Output:

```text
name
```

Because Bash treats it as ordinary text.

---

# Double Quotes vs Single Quotes

This is one of the most common beginner mistakes.

---

## Correct

```bash
echo "Hello $name"
```

Output:

```text
Hello Ahmed
```

Bash expands the variable.

---

## Incorrect

```bash
echo 'Hello $name'
```

Output:

```text
Hello $name
```

The variable is **NOT expanded**.

---

# Why?

Double quotes allow Bash to interpret variables.

Single quotes tell Bash:

> Treat everything literally.

---

# Demonstration

Suppose:

```bash
name="Jessica"
```

Command:

```bash
echo "$name"
```

Output:

```text
Jessica
```

Now:

```bash
echo '$name'
```

Output:

```text
$name
```

# How Variables Work

```text
User Types

Jessica
     │
     ▼

read name
     │
     ▼

Variable

name = Jessica
     │
     ▼

echo "Hello $name"
     │
     ▼

Hello Jessica
```

# Common Mistakes

## Forgetting the Dollar Sign

Wrong:

```bash
echo "Hello name"
```

Correct:

```bash
echo "Hello $name"
```

---

## Using Single Quotes

Wrong:

```bash
echo 'Hello $name'
```

Correct:

```bash
echo "Hello $name"
```

---

## Forgetting Execute Permission

Wrong:

```bash
./hello.sh
```

Error:

```text
Permission denied
```

Fix:

```bash
chmod u+x hello.sh
```
