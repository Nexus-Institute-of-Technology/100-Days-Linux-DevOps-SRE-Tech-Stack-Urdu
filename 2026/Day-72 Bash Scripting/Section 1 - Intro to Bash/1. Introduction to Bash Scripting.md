# Understanding Terminal, Console, and Shell

Many beginners confuse these three terms.

Although they are closely related, they are not exactly the same.

---

# What is a Terminal?

Historically, a terminal was a physical device that looked similar to a typewriter.

Users typed commands into the terminal and received output from the computer.

Today, a terminal is simply a software application that allows users to interact with the operating system.

Examples include:

- Linux Terminal
- macOS Terminal
- Windows Terminal
- PowerShell Terminal
- PuTTY
- MobaXterm

A terminal is simply the interface where commands are entered.

---

# What is a Console?

Originally, a console referred to a physical device connected directly to servers or networking equipment.

Today, the words **console** and **terminal** are often used interchangeably.

In modern Linux administration:

- Terminal = Console

Most people mean the same thing.

---

# What is a Shell?

The **Shell** is completely different.

A shell is a **command-line interpreter**.

It is a software program that:

- Reads commands.
- Understands them.
- Executes the appropriate programs.
- Displays the results.

Without a shell:

- You could type commands.
- But nothing would happen.

The shell acts as the interpreter between the user and the operating system.

---

# Shell Execution Flow

```text
User Types Command
        │
        ▼
     Terminal
        │
        ▼
      Shell
        │
        ▼
Operating System
        │
        ▼
Program Executes
        │
        ▼
Output Returned
        │
        ▼
Terminal Displays Output
```

---

# Examples of Linux Shells

Linux supports many different shells.

Some common shells are:

- Bourne Shell (sh)
- Bourne Again Shell (bash)
- Dash Shell
- Z Shell (zsh)
- Korn Shell (ksh)
- C Shell (csh)

The most commonly used shell today is:

```text
Bash (Bourne Again Shell)
```

---

# Viewing Installed Shells

Linux stores the list of available shells in:

```bash
cat /etc/shells
```

Example Output:

```text
/bin/sh
/bin/bash
/bin/dash
/bin/zsh
```

This file lists all shells currently installed on the system.

---

# Installing Another Shell

For example, to install the Z Shell:

```bash
sudo apt install zsh
```

After installation:

```bash
cat /etc/shells
```

You should now see:

```text
/bin/zsh
```

---

# Checking the Current Shell

Display your current shell:

```bash
echo $SHELL
```

Example Output:

```text
/bin/bash
```

---

# Changing Your Login Shell

Use the `chsh` command:

```bash
chsh
```

Or specify the shell:

```bash
chsh -s /bin/zsh
```

After changing your shell:

- Log out.
- Log back in.

The new shell becomes active.

Verify:

```bash
echo $SHELL
```

---

# Viewing User Login Shell

The user's default shell is stored in:

```text
/etc/passwd
```

Example:

```bash
grep username /etc/passwd
```

Example Output:

```text
elliot:x:1000:1000::/home/elliot:/bin/bash
```

The last field shows the user's default login shell.

# Creating a Scripts Directory

Move to your home directory:

```bash
cd
```

Create a directory:

```bash
mkdir scripts
```

Move into it:

```bash
cd scripts
```

Verify:

```bash
pwd
```

Example Output:

```text
/home/elliot/scripts
```

---

# Creating Your First Script

Create an empty file:

```bash
touch hello.sh
```

The `.sh` extension is commonly used for shell scripts.

---

# Editing the Script

Open the file using your preferred editor.

Examples:

```bash
vi hello.sh
```

or

```bash
vim hello.sh
```

or

```bash
nano hello.sh
```

Insert the following line:

```bash
echo "Hello Friend"
```

Save the file and exit the editor.

---

# Viewing the Script

Display the contents:

```bash
cat hello.sh
```

Output:

```bash
echo "Hello Friend"
```

---

# Running the Script with Bash

Execute:

```bash
bash hello.sh
```

Output:

```text
Hello Friend
```

The Bash shell interprets the script and executes the `echo` command.

---

# Running the Script with sh

Execute:

```bash
sh hello.sh
```

Output:

```text
Hello Friend
```

The Bourne Shell also understands this simple script.

---

# Different Shells Can Execute the Script

Simple shell scripts can often be executed using different shells.

Example:

```bash
bash hello.sh
```

or

```bash
sh hello.sh
```

Both produce:

```text
Hello Friend
```

However, advanced Bash-specific features require the Bash shell.

# 📖 Key Takeaways

- A shell script is simply a text file containing Linux commands.
- A terminal provides the interface for entering commands.
- A shell interprets and executes those commands.
- Linux supports multiple shells.
- Bash is the most widely used Linux shell.

- A `.sh` file can be executed using different shells.
