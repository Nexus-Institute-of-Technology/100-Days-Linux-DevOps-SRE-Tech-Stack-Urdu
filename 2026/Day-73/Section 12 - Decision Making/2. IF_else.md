# Module 12: Decision Making in Bash — `if...else` Statements

## Lesson Overview

In the previous lesson, we learned how to create a simple `if` statement.

A simple `if` statement runs commands only when a condition is true.

In this lesson, we will learn how to use an `else` clause so that the script can perform a different action when the condition is false.

For example:

> If the current user is `root`, display “You are root.”  
> Otherwise, display “You are a regular user.”

---

## Learning Objectives

By the end of this lesson, students will be able to:

- Explain the purpose of an `if...else` statement.
- Describe the difference between a true and false condition.
- Write a complete `if...else` structure.
- Use `whoami` in a condition.
- Use `$EUID` to check for root privileges.
- Understand where `else` is placed.
- Understand why `fi` is still required.
- Test a script as both a normal user and as `root`.
- Troubleshoot common `if...else` errors.

---

# 1. Review: Simple `if`

A simple `if` statement has this structure:

```bash
if [[ condition ]]
then
    commands
fi
```

Example:

```bash
#!/bin/bash

current_user=$(whoami)

if [[ "$current_user" == "root" ]]
then
    echo "You are root."
fi
```

If the condition is true, the message appears.

If the condition is false, the script displays nothing.

---

# 2. Why Use `else`?

The `else` clause allows the script to perform another action when the condition is false.

Real-life example:

> If the weather is cold, stay home.  
> Else, go outside.

Bash example:

```bash
if [[ condition ]]
then
    commands_when_true
else
    commands_when_false
fi
```

---

# 3. Basic `if...else` Syntax

```bash
if [[ condition ]]
then
    commands_when_true
else
    commands_when_false
fi
```

Another common style is:

```bash
if [[ condition ]]; then
    commands_when_true
else
    commands_when_false
fi
```

Both styles are correct.

---

## Syntax Explanation

| Keyword | Purpose |
|---|---|
| `if` | Begins the condition |
| `[[ condition ]]` | The test Bash evaluates |
| `then` | Begins commands that run when the condition is true |
| `else` | Begins commands that run when the condition is false |
| `fi` | Ends the entire conditional statement |

---

# 4. How `if...else` Works

Bash checks the condition.

- If the condition is true, the `then` section runs.
- If the condition is false, the `else` section runs.
- Only one section runs.

Example:

```bash
if [[ 10 -gt 5 ]]
then
    echo "The condition is true."
else
    echo "The condition is false."
fi
```

Output:

```text
The condition is true.
```

---

## False Condition Example

```bash
if [[ 2 -gt 5 ]]
then
    echo "The condition is true."
else
    echo "The condition is false."
fi
```

Output:

```text
The condition is false.
```

# 5. Root User Example with `whoami`

Create a script that checks the current username.

```bash
#!/bin/bash

current_user=$(whoami)

if [[ "$current_user" == "root" ]]
then
    echo "You are root."
else
    echo "You are a regular user."
fi
```

---

## How the Script Works

```bash
current_user=$(whoami)
```

Runs the `whoami` command and stores the result in `current_user`.

```bash
if [[ "$current_user" == "root" ]]
```

Checks whether the stored username is equal to `root`.

```bash
then
    echo "You are root."
```

Runs when the condition is true.

```bash
else
    echo "You are a regular user."
```

Runs when the condition is false.

```bash
fi
```

Ends the entire `if...else` statement.

# 10. Recommended Root Check with `$EUID`

A more direct way to check for root is to use:

```bash
$EUID
```

The root user has an effective user ID of:

```text
0
```

Example:

```bash
#!/bin/bash

if [[ $EUID -eq 0 ]]
then
    echo "You are root."
else
    echo "You are a regular user."
fi
```

---

## Explanation

| Expression | Meaning |
|---|---|
| `$EUID` | Effective user ID |
| `-eq` | Numerically equal to |
| `0` | Root user ID |

---

# 12. Difference Between Simple `if` and `if...else`

## Simple `if`

```bash
if [[ condition ]]
then
    command
fi
```

Behavior:

- True: runs the command.
- False: does nothing.

---

## `if...else`

```bash
if [[ condition ]]
then
    command_for_true
else
    command_for_false
fi
```

Behavior:

- True: runs the `then` section.
- False: runs the `else` section.

# 19. Command Success Example

An `if...else` statement can check whether a command succeeds.

```bash
#!/bin/bash

if grep -q "^root:" /etc/passwd
then
    echo "The root account exists."
else
    echo "The root account was not found."
fi
```

The `if` statement checks the exit status of `grep`.

# 24. Spacing Rules

Correct:

```bash
if [[ "$user" == "root" ]]
then
    echo "Root"
else
    echo "Not root"
fi
```

Incorrect:

```bash
if [["$user" == "root"]]
```

Incorrect:

```bash
if [[ "$user"=="root" ]]
```

Correct same-line style:

```bash
if [[ "$user" == "root" ]]; then
    echo "Root"
else
    echo "Not root"
fi
```

# 25. Common Mistakes

## Mistake 1: Placing `fi` Before `else`

Incorrect:

```bash
if [[ condition ]]
then
    command
fi
else
    other_command
```

Correct:

```bash
if [[ condition ]]
then
    command
else
    other_command
fi
```

---

## Mistake 2: Forgetting `fi`

Incorrect:

```bash
if [[ condition ]]
then
    command
else
    other_command
```

Correct:

```bash
if [[ condition ]]
then
    command
else
    other_command
fi
```

---

## Mistake 3: Writing `elseif`

Bash does not use:

```text
elseif
```

Bash uses:

```text
elif
```

The `elif` statement will be covered in the next lesson.

---

## Mistake 4: Using the Wrong Operator

Text:

```bash
[[ "$user" == "root" ]]
```

Number:

```bash
[[ $EUID -eq 0 ]]
```

---

## Mistake 5: Forgetting Quotes Around Text Variables

Preferred:

```bash
[[ "$username" == "root" ]]
```

---

## Mistake 6: Expecting Both Sections to Run

Only one branch runs:

- Either `then`
- Or `else`

They do not both run during the same condition check.

# 35. Final Challenge: User Management Pre-Check

Create a script named:

```text
user_management_check.sh
```

The script must:

1. Check whether the script is running as root.
2. If root, ask for a username.
3. Check whether that user already exists.
4. Display the appropriate result.
5. If not root, display an error.

## Solution

```bash
#!/bin/bash

if [[ $EUID -eq 0 ]]
then
    echo "Root access confirmed."
    echo

    read -r -p "Enter a username to check: " username

    if id "$username" &>/dev/null
    then
        echo "User '$username' already exists."
    else
        echo "User '$username' does not exist."
    fi
else
    echo "Error: This script must be run as root."
    echo "Try: sudo $0"
    exit 1
fi
```

This solution also introduces a nested `if`, which will be covered in more detail later.

# Summary

The basic `if...else` structure is:

```bash
if [[ condition ]]
then
    commands_when_true
else
    commands_when_false
fi
```

Example:

```bash
current_user=$(whoami)

if [[ "$current_user" == "root" ]]
then
    echo "You are root."
else
    echo "You are a regular user."
fi
```

Recommended root check:

```bash
if [[ $EUID -eq 0 ]]
then
    echo "You are root."
else
    echo "You are not root."
fi
```

Important points:

- `then` runs when the condition is true.
- `else` runs when the condition is false.
- Only one branch runs.
- `fi` closes the whole statement.
- Spaces inside the condition are important.
- Use `==` for text comparisons.
- Use operators such as `-eq` for numeric comparisons.
- Use `$EUID` for a reliable root privilege check.
- Use `bash -n` to check syntax.
- Use `bash -x` to trace execution.

The next lesson will cover `if...elif...else`, which allows a script to test more than two possible conditions.
