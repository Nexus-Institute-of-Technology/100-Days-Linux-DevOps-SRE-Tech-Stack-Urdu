# Module 12: Decision Making in Bash — `if...elif...else` Statements

## Lesson Overview

In the previous lesson, we learned how to use an `if...else` statement.

An `if...else` statement is useful when a script has only two possible outcomes:

- The condition is true.
- The condition is false.

In real scripts, we often need to test more than two possibilities.

For example:

- If today is Monday, go to the gym.
- Else if today is Tuesday, go swimming.
- Else if today is Wednesday, work from home.
- Else, relax at home.

In Bash, multiple conditions are handled with:

```bash
elif
```

The word `elif` means:

```text
else if
```

---

## Learning Objectives

By the end of this lesson, students will be able to:

- Explain why `elif` is used.
- Write an `if...elif...else` statement.
- Test several conditions in the correct order.
- Use command-line arguments in conditions.
- Compare integer values.
- Understand how Bash stops after the first true condition.
- Validate user input before performing numeric comparisons.
- Build an age-classification script.
- Troubleshoot common `elif` syntax errors.

---

# 1. Review: `if...else`

An `if...else` statement tests one condition.

```bash
if [[ condition ]]
then
    commands_when_true
else
    commands_when_false
fi
```

Example:

```bash
#!/bin/bash

if [[ $EUID -eq 0 ]]
then
    echo "You are root."
else
    echo "You are a regular user."
fi
```

This script has two possible outcomes.

---

# 2. Why Use `elif`?

Use `elif` when there are more than two possible conditions.

Example:

```text
If age is less than 13:
    You are a kid.

Else if age is less than 20:
    You are a teenager.

Else if age is less than 65:
    You are an adult.

Else:
    You are an elder.
```

A simple `if...else` cannot clearly handle all four categories.

---

# 3. Basic `if...elif...else` Syntax

```bash
if [[ condition1 ]]
then
    commands_for_condition1

elif [[ condition2 ]]
then
    commands_for_condition2

elif [[ condition3 ]]
then
    commands_for_condition3

else
    commands_when_all_conditions_are_false
fi
```

A more compact style is:

```bash
if [[ condition1 ]]; then
    commands_for_condition1
elif [[ condition2 ]]; then
    commands_for_condition2
elif [[ condition3 ]]; then
    commands_for_condition3
else
    default_commands
fi
```

Both styles are correct.

---

## Syntax Explanation

| Keyword | Purpose |
|---|---|
| `if` | Begins the first condition |
| `then` | Begins commands for a true condition |
| `elif` | Introduces another condition |
| `else` | Runs when all earlier conditions are false |
| `fi` | Ends the entire conditional statement |

---

# 4. Important Rule: Only One Branch Runs

Bash checks conditions from top to bottom.

As soon as Bash finds the first true condition:

1. It runs that branch.
2. It skips all remaining branches.
3. It continues after `fi`.

Example:

```bash
number=5

if [[ $number -lt 10 ]]
then
    echo "Less than 10"

elif [[ $number -lt 20 ]]
then
    echo "Less than 20"

else
    echo "20 or more"
fi
```

Output:

```text
Less than 10
```

Although `5` is also less than `20`, Bash does not test the second branch after the first condition is true.

---

# 7. How the Age Script Works

## First Condition

```bash
if [[ $age -lt 13 ]]
```

This checks:

> Is the age less than 13?

If true:

```bash
echo "You are a kid."
```

runs.

---

## Second Condition

```bash
elif [[ $age -lt 20 ]]
```

This condition is checked only if the first condition was false.

Because the first test already proved that the age is not less than 13, this branch effectively represents:

```text
13 through 19
```

---

## Third Condition

```bash
elif [[ $age -lt 65 ]]
```

This condition is checked only if the first two conditions were false.

Therefore, the age must already be at least 20.

This branch effectively represents:

```text
20 through 64
```

---

## Final `else`

```bash
else
    echo "You are an elder."
```

This runs only when all earlier conditions are false.

That means the age is:

```text
65 or older
```

# 12. Why the Order Matters

Conditions must normally be arranged from the most specific or smallest range to the broadest range.

Correct order:

```bash
if [[ $age -lt 13 ]]
elif [[ $age -lt 20 ]]
elif [[ $age -lt 65 ]]
else
```

Incorrect order:

```bash
if [[ $age -lt 65 ]]
elif [[ $age -lt 20 ]]
elif [[ $age -lt 13 ]]
```

If the age is `11`, the first condition:

```bash
[[ 11 -lt 65 ]]
```

is true.

The script would incorrectly classify the user as an adult before reaching the kid condition.

# 13. Improved Script with Argument Validation

The basic script assumes the user provides an age.

A better script checks whether exactly one argument was provided.

```bash
#!/bin/bash

if [[ $# -ne 1 ]]
then
    echo "Usage: $0 AGE"
    exit 1
fi

age=$1
```

---

## Explanation

| Expression | Meaning |
|---|---|
| `$#` | Number of command-line arguments |
| `-ne` | Not equal to |
| `1` | Required number of arguments |
| `$0` | Script name |

If the argument is missing:

```bash
./age.sh
```

the script displays:

```text
Usage: ./age.sh AGE
```

# 14. Validate That the Age Is an Integer

The user might enter:

```bash
./age.sh hello
```

We should verify that the argument is a whole number.

```bash
if [[ ! "$age" =~ ^[0-9]+$ ]]
then
    echo "Error: Age must be a non-negative whole number."
    exit 1
fi
```

---

## Pattern Explanation

```text
^[0-9]+$
```

| Part | Meaning |
|---|---|
| `^` | Beginning of input |
| `[0-9]` | Any digit |
| `+` | One or more digits |
| `$` | End of input |

Valid examples:

```text
0
12
25
77
```

Invalid examples:

```text
hello
12abc
-5
18.5
```

# 16. Complete Validated Age Script

```bash
#!/bin/bash

then

elif [[ $age -lt 20 ]]
then
    echo "You are a teenager."

elif [[ $age -lt 65 ]]

    echo "You are an adult."

    echo "You are an elder."
fi
```

# 18. Alternative with Explicit Ranges

The original script works because earlier conditions eliminate smaller values.

We can also write explicit ranges using `&&`.

```bash
if [[ $age -ge 0 && $age -lt 13 ]]
then
    echo "You are a kid."

elif [[ $age -ge 13 && $age -lt 20 ]]
then
    echo "You are a teenager."

elif [[ $age -ge 20 && $age -lt 65 ]]
then
    echo "You are an adult."

else
    echo "You are an elder."
fi
```

---

## Understanding `&&`

The operator:

```bash
&&
```

means:

```text
AND
```

Both conditions must be true.

Example:

```bash
[[ $age -ge 13 && $age -lt 20 ]]
```

means:

> The age must be greater than or equal to 13 and less than 20.

The script checks the highest grade first:


If `95` were tested against `60` first, it would incorrectly match the lower grade.

# 25. Multiple `elif` Branches

A script may contain as many `elif` branches as needed.

```bash
if [[ condition1 ]]
then
    command1

elif [[ condition2 ]]
then
    command2

elif [[ condition3 ]]
then
    command3

elif [[ condition4 ]]
then
    command4

else
    default_command
fi
```

There is only:

- One opening `if`
- One final `fi`

All `elif` branches belong to the same conditional statement.

---

# 26. Is `else` Required?

No.

An `if...elif` structure may end without `else`.

Example:

```bash
if [[ "$day" == "Monday" ]]
then
    echo "Go to the gym."

elif [[ "$day" == "Tuesday" ]]
then
    echo "Go swimming."
fi
```

If neither condition is true, the script displays nothing.

Using `else` is often helpful because it handles unexpected or unmatched values.

# 27. Common Mistakes

## Mistake 1: Writing `else if`

Incorrect in Bash:

```bash
else if [[ condition ]]
```

Correct:

```bash
elif [[ condition ]]
```

---

## Mistake 2: Writing `elseif`

Incorrect:

```bash
elseif [[ condition ]]
```

Correct:

```bash
elif [[ condition ]]
```

---

## Mistake 3: Adding More Than One `fi`

Incorrect:

```bash
if [[ condition1 ]]
then
    command1
fi

elif [[ condition2 ]]
then
    command2
fi
```

Correct:

```bash
if [[ condition1 ]]
then
    command1

elif [[ condition2 ]]
then
    command2
fi
```

Only one final `fi` closes the whole chain.

---

## Mistake 4: Forgetting `then` After `elif`

Incorrect:

```bash
elif [[ $age -lt 20 ]]
    echo "Teenager"
```

Correct:

```bash
elif [[ $age -lt 20 ]]
then
    echo "Teenager"
```

---

## Mistake 5: Putting Conditions in the Wrong Order

Incorrect:

```bash
if [[ $age -lt 65 ]]
then
    echo "Adult"

elif [[ $age -lt 13 ]]
then
    echo "Kid"
fi
```

A child would match the first condition and be classified as an adult.

---

## Mistake 6: Not Validating Input

Running:

```bash
./age.sh hello
```

may produce an arithmetic error or unreliable result.

Validate first:

```bash
if [[ ! "$age" =~ ^[0-9]+$ ]]
then
    echo "Error: Enter a valid age."
    exit 1
fi
```

---

## Mistake 7: Forgetting Spaces

Incorrect:

```bash
elif[[$age -lt 20]]
```

Correct:

```bash
elif [[ $age -lt 20 ]]
```

# 36. Final Challenge: System Health Classification

Create a script named:

```text
system_health.sh
```

The script must:

1. Ask for a disk usage percentage.
2. Validate that the input is a number from 0 through 100.
3. Classify the status:
   - 0–69: Normal
   - 70–84: Warning
   - 85–94: High
   - 95–100: Critical
4. Display the selected status.

## Final Challenge Solution

```bash
#!/bin/bash

read -r -p "Enter disk usage percentage (0-100): " usage

if [[ ! "$usage" =~ ^[0-9]+$ ]]
then
    echo "Error: Enter a whole number."
    exit 1
fi

if [[ $usage -lt 0 || $usage -gt 100 ]]
then
    echo "Error: Percentage must be between 0 and 100."
    exit 1
fi

if [[ $usage -lt 70 ]]
then
    status="Normal"

elif [[ $usage -lt 85 ]]
then
    status="Warning"

elif [[ $usage -lt 95 ]]
then
    status="High"

else
    status="Critical"
fi

echo "Disk usage: ${usage}%"
echo "Disk status: $status"
```

# Summary

The basic structure is:

```bash
if [[ condition1 ]]
then
    commands1

elif [[ condition2 ]]
then
    commands2

elif [[ condition3 ]]
then
    commands3

else
    default_commands
fi
```

Age example:

```bash
if [[ $age -lt 13 ]]
then
    echo "You are a kid."

elif [[ $age -lt 20 ]]
then
    echo "You are a teenager."

elif [[ $age -lt 65 ]]
then
    echo "You are an adult."

else
    echo "You are an elder."
fi
```

Important points:

- `elif` means `else if`.
- Use one opening `if`.
- Use one final `fi`.
- Add as many `elif` branches as required.
- Conditions are checked from top to bottom.
- Bash runs only the first matching branch.
- Place conditions in a logical order.
- Validate input before numeric comparisons.
- Test values at category boundaries.
- Use `bash -n` to check syntax.
- Use `bash -x` to trace the decision flow.
