# Module 12: Decision Making in Bash — Simple `if` Statements

## Lesson Overview

Decision making allows a Bash script to check a condition and decide whether a command should run.

For example:

> If the current user is `root`, display a message.

This lesson introduces the simplest Bash decision-making structure: the `if` statement.

---

By the end of this lesson, students will be able to:

- Explain what decision making means in Bash.
- Write a simple `if` statement.
- Use `if`, `then`, and `fi`.
- Compare text and numeric values.
- Check whether a script is running as `root`.
- Understand why spaces are important in test conditions.
- Test files and directories.
- Troubleshoot common conditional-statement errors.

# 1. What Is Decision Making?

A condition is a question that has one of two possible results:

```text
True
False
```

A Bash script can run commands only when a condition is true.

Real-life example:

> If the weather is cold, stay home.

Bash example:

```bash
if [[ condition ]]
then
    command
fi
```

When the condition is true, the command runs. When it is false, the command is skipped.

---

# 2. Basic `if` Statement Syntax

```bash
if [[ condition ]]
then
    commands
fi
```

Another valid format is:

```bash
if [[ condition ]]; then
    commands
fi
```

## Syntax Explanation

| Keyword or expression | Purpose |
|---|---|
| `if` | Begins the conditional statement |
| `[[ condition ]]` | The test Bash evaluates |
| `then` | Begins the commands that run when the condition is true |
| `commands` | Actions to perform |
| `fi` | Ends the `if` statement |

The word `fi` is `if` written backward.

---

# 3. First Simple Example

```bash
#!/bin/bash

if [[ 10 -gt 5 ]]
then
    echo "10 is greater than 5."
fi
```

Output:

```text
10 is greater than 5.
```

The condition is true, so the `echo` command runs.

## False Condition

```bash
#!/bin/bash

if [[ 2 -gt 5 ]]
then
    echo "2 is greater than 5."
fi
```

This script displays nothing because the condition is false.

A simple `if` statement has no alternative action. The `else` statement will be covered in the next lesson.

---

# 4. Spaces Are Required

Correct:

```bash
if [[ "$user" == "root" ]]
```

Incorrect:

```bash
if [["$user" == "root"]]
```

Incorrect:

```bash
if [[ "$user"=="root" ]]
```

Preferred:

```bash
if [[ "$user" == "root" ]]
```

Spaces separate the brackets, values, and operators so Bash can interpret the expression correctly.

# 5. The `whoami` Command

The command:

```bash
whoami
```

displays the effective username.

Example for a normal user:

```text
student
```

Example for the root user:

```text
root
```

# 6. Command Substitution

Command substitution runs a command and stores its output.

Syntax:

```bash
variable=$(command)
```

Example:

```bash
current_user=$(whoami)
```

Display the value:

```bash
echo "$current_user"
```

# 7. Root User Check with `whoami`

```bash
#!/bin/bash

current_user=$(whoami)

if [[ "$current_user" == "root" ]]
then
    echo "You are root."
fi
```

If the script runs as `root`, it displays:

```text
You are root.
```

If it runs as another user, it displays nothing.

# 9. Why Use `./root.sh`?

The command:

```bash
./root.sh
```

means:

> Execute `root.sh` from the current directory.

The current directory is normally not included in the user's `PATH`.

Display the `PATH`:

```bash
echo "$PATH"
```

Because the shell may not search the current directory automatically, use:

```bash
./script_name
```

---

# 10. Same-Line `then` Syntax

This is valid:

```bash
if [[ "$current_user" == "root" ]]; then
    echo "You are root."
fi
```

The semicolon separates the condition from `then`.

Both styles are correct:

```bash
if [[ condition ]]
then
    command
fi
```

and:

```bash
if [[ condition ]]; then
    command
fi
```

# 11. Recommended Root Check with `$EUID`

Bash provides the variable:

```bash
$EUID
```

It stores the effective user ID.

Root always has user ID:

```text
0
```

Check your effective user ID:

```bash
echo "$EUID"
```

Root check:

```bash
#!/bin/bash

if [[ $EUID -eq 0 ]]
then
    echo "You are root."
fi
```

## Explanation

| Expression | Meaning |
|---|---|
| `$EUID` | Effective user ID |
| `-eq` | Numerically equal to |
| `0` | Root user ID |

This method is usually more reliable than comparing usernames.

---

# 12. Root-Only Script Pattern

Administrative scripts often stop when the current user is not root.

```bash
#!/bin/bash

if [[ $EUID -ne 0 ]]
then
    echo "Error: Run this script as root or with sudo."
    exit 1
fi

echo "Root access confirmed."
```

The test:

```bash
[[ $EUID -ne 0 ]]
```

means:

> The effective user ID is not equal to zero.

The command:

```bash
exit 1
```

stops the script with an error status.

# 13. Text Comparison Operators

| Operator | Meaning |
|---|---|
| `==` | Text values are equal |
| `!=` | Text values are not equal |
| `-z` | String is empty |
| `-n` | String is not empty |

## Equal Text

```bash
name="Ali"

if [[ "$name" == "Ali" ]]
then
    echo "The name is Ali."
fi
```

## Text Not Equal

```bash
if [[ "$name" != "Ali" ]]
then
    echo "The name is not Ali."
fi
```

## Empty String

```bash
if [[ -z "$name" ]]
then
    echo "No name was entered."
fi
```

## Non-Empty String

```bash
if [[ -n "$name" ]]
then
    echo "A name was entered."
fi
```

# 14. Numeric Comparison Operators

| Operator | Meaning |
|---|---|
| `-eq` | Equal to |
| `-ne` | Not equal to |
| `-gt` | Greater than |
| `-ge` | Greater than or equal to |
| `-lt` | Less than |
| `-le` | Less than or equal to |

Example:

```bash
age=20

if [[ $age -ge 18 ]]
then
    echo "The user is an adult."
fi
```

# 15. File and Directory Tests

| Test | Meaning |
|---|---|

| `-f` | Regular file exists |
| `-d` | Directory exists |
| `-r` | Path is readable |
| `-w` | Path is writable |
| `-x` | Path is executable |
| `-s` | File exists and is not empty |

# 19. Validate Numeric Input

```bash
#!/bin/bash

read -r -p "Enter an integer: " number

if [[ "$number" =~ ^-?[0-9]+$ ]]
then
    echo "You entered a valid integer."
fi
```

The pattern accepts:

```text
10
0
-5
250
```

It rejects:

```text
hello
5.5
12abc
```

# 20. Exit Status and Conditions

Linux commands return an exit status.

| Status | Meaning |
|---:|---|
| `0` | Success or true |
| Non-zero | Failure or false |

Test a true condition:

```bash
[[ 10 -gt 5 ]]
echo $?
```

Output:

```text
0
```

Test a false condition:

```bash
[[ 2 -gt 5 ]]
echo $?
```

Output:

```text
1
```

An `if` statement uses this success or failure result.

# 21. Use a Command Directly as a Condition

```bash
if grep -q "^root:" /etc/passwd
then
    echo "The root account exists."
fi
```

The message appears only when `grep` finds the matching line.

The `-q` option prevents `grep` from displaying the match.

# 22. Comments in Conditional Scripts

```bash
#!/bin/bash

# Store the effective username
current_user=$(whoami)

# Display a message only when the user is root
if [[ "$current_user" == "root" ]]
then
    echo "You are root."
fi
```

Comments begin with `#` and are ignored by Bash.

# 23. Common Mistakes

## Missing Spaces

Incorrect:

```bash
if [["$user" == "root"]]
```

Correct:

```bash
if [[ "$user" == "root" ]]
```

## Missing `then`

Incorrect:

```bash
if [[ "$user" == "root" ]]
    echo "You are root."
fi
```

Correct:

```bash
if [[ "$user" == "root" ]]
then
    echo "You are root."
fi
```

## Missing `fi`

Every `if` statement must end with:

```bash
fi
```

## Wrong Comparison Operator

Use text comparison:

```bash
[[ "$user" == "root" ]]
```

Use numeric comparison:

```bash
[[ $EUID -eq 0 ]]
```

## Expecting Output for a False Condition

A simple `if` statement does nothing when the condition is false. This is normal.

## Permission Denied

```text
bash: ./root.sh: Permission denied
```

Fix:

```bash
chmod +x root.sh
```

# 24. Check and Debug the Script



# 29. Student Challenge: Root-Only Administration Script

Create:

```text
user_admin_check.sh
```

Requirements:

1. Check whether the effective user ID is root.
2. Display an error for a normal user.
3. Exit with status `1` when not root.
4. Display confirmation when running as root.

## Solution

```bash
#!/bin/bash

if [[ $EUID -ne 0 ]]
then
    echo "Error: This script must be run as root."
    echo "Try: sudo $0"
    exit 1
fi

echo "Root access confirmed."
echo "The administration commands may now continue."
```

Test as a normal user:

```bash
./user_admin_check.sh
```

Test with root privileges:

```bash
sudo ./user_admin_check.sh
```

# Summary

A simple Bash `if` statement is written as:

```bash
if [[ condition ]]
then
    commands
fi
```

Root check with `whoami`:

```bash
current_user=$(whoami)

if [[ "$current_user" == "root" ]]
then
    echo "You are root."
fi
```

Recommended root check:

```bash
if [[ $EUID -eq 0 ]]
then
    echo "You are root."
fi
```

Important points:

- `if` begins the condition.
- `then` begins the commands.
- `fi` ends the statement.
- Spaces around the condition are required.
- A simple `if` statement does nothing when its condition is false.
- Root has an effective user ID of `0`.
- Use `bash -n` to check syntax.
- Use `bash -x` to debug execution.

The next lesson introduces `if...else`, allowing the script to perform one action when the condition is true and another action when it is false.
