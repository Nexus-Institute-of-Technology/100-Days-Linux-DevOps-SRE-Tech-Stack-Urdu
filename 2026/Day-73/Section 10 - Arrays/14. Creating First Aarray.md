# Module 12: Bash Arrays — Creating Arrays

## Lesson Overview

In this lesson, we begin learning how to create and use arrays in Bash scripts.

An **array** allows us to store multiple values under a single variable name. This makes scripts easier to read, organize, and maintain.

# 1. What Is an Array?

An array is a collection or list of multiple values stored under one variable name.

You can think of an array as a box containing several related items.

For example, instead of creating five separate variables:

```bash
file1="f1.txt"
file2="f2.txt"
file3="f3.txt"
file4="f4.txt"
file5="f5.txt"
```

we can store all five file names in one array:

```bash
files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")
```

The array is named:

```text
files
```

It contains five elements.

---

# 2. Why Use Arrays?

Arrays help us:

- Store related values together.
- Reduce the number of variables in a script.
- Avoid repeating code.
- Improve script readability.
- Make scripts easier to maintain.
- Process several items using loops.
- Add or remove values more easily.

---

## Without an Array

The following script uses five separate variables:

```bash
#!/bin/bash

file1="f1.txt"
file2="f2.txt"
file3="f3.txt"
file4="f4.txt"
file5="f5.txt"

touch "$file1"
touch "$file2"
touch "$file3"
touch "$file4"
touch "$file5"
```

This script works, but it is repetitive.

If we had 100 file names, we would need 100 variables and many repeated commands.

---

## With an Array

A cleaner approach is:

```bash
#!/bin/bash

files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")
```

All related file names are now stored in one array.

Later, we can use a loop to process every element.

---

# 3. Bash Is Data-Type Blind

Bash variables do not require us to declare a fixed data type.

For example, Bash does not require declarations such as:

```text
integer
string
float
```

A Bash variable may contain text, numbers, file names, or other values.

The same is true for arrays. A Bash array may contain different kinds of values.

Example:

```bash
items=("server1" 25 "active" "/var/log/messages")
```

This array contains:

- A server name
- A number
- A status
- A file path

Although Bash allows mixed values, related values should normally be grouped together for clarity.

---

# 4. Syntax for Creating an Array

The basic syntax is:

```bash
array_name=("value1" "value2" "value3")
```

Example:

```bash
files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")
```

---

## Syntax Breakdown

```bash
files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")
```

| Part | Meaning |
|---|---|
| `files` | Name of the array |
| `=` | Assignment operator |
| `(` and `)` | Contain the array elements |
| `"f1.txt"` | First element |
| `"f2.txt"` | Second element |
| `"f3.txt"` | Third element |
| `"f4.txt"` | Fourth element |
| `"f5.txt"` | Fifth element |

---

## Important Spacing Rule

Do not place spaces around the equal sign.

Correct:

```bash
files=("f1.txt" "f2.txt")
```

Incorrect:

```bash
files = ("f1.txt" "f2.txt")
```

The incorrect version causes Bash to interpret `files` as a command.

---

# 5. Array Elements

Each value stored inside an array is called an **element**.

Example:

```bash
files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")
```

The elements are:

| Position | Element |
|---:|---|
| First | `f1.txt` |
| Second | `f2.txt` |
| Third | `f3.txt` |
| Fourth | `f4.txt` |
| Fifth | `f5.txt` |

Bash indexed arrays use index numbers that begin at `0`.

Therefore, the actual indexes are:

| Index | Element |
|---:|---|
| `0` | `f1.txt` |
| `1` | `f2.txt` |
| `2` | `f3.txt` |
| `3` | `f4.txt` |
| `4` | `f5.txt` |

Accessing array elements will be covered in the next lesson.

# 8. Preview: Processing an Array with a Loop

The next lessons will explain array access and loops in more detail.

For now, observe this improved version:

```bash
#!/bin/bash

files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")

for file in "${files[@]}"
do
    touch "$file"
done
```

This script processes every element in the `files` array.

The same `touch` command is written only once.

---

## Explanation

```bash
for file in "${files[@]}"
```

This reads each element in the array.

```bash
do
```

This begins the commands to repeat.

```bash
touch "$file"
```

This creates or updates the timestamp of the current file.

```bash
done
```

This ends the loop.

# 9. Quotation Marks in Arrays

Use quotation marks around array values, especially when values may contain spaces.

Example:

```bash
documents=("report.txt" "student notes.txt" "final project.txt")
```

Without quotation marks:

```bash
documents=(report.txt student notes.txt final project.txt)
```

Bash would treat each word as a separate element.

---

## Correct Example

```bash
documents=("report.txt" "student notes.txt" "final project.txt")
```

This array contains three elements.

---

## Incorrect or Unintended Example

```bash
documents=(report.txt student notes.txt final project.txt)
```

This array contains five elements:

```text
report.txt
student
notes.txt
final
project.txt
```

# 11. Common Mistakes

## Mistake 1: Spaces Around `=`

Incorrect:

```bash
files = ("f1.txt" "f2.txt")
```

Correct:

```bash
files=("f1.txt" "f2.txt")
```

---

## Mistake 2: Using Commas

Incorrect:

```bash
files=("f1.txt", "f2.txt", "f3.txt")
```

Bash arrays do not require commas.

Correct:

```bash
files=("f1.txt" "f2.txt" "f3.txt")
```

---

## Mistake 3: Forgetting Parentheses

Incorrect:

```bash
files="f1.txt" "f2.txt" "f3.txt"
```

Correct:

```bash
files=("f1.txt" "f2.txt" "f3.txt")
```

---

## Mistake 4: Forgetting Quotes Around Values with Spaces

Incorrect:

```bash
students=(Ali Khan Mary Smith)
```

This creates four elements.

Correct:

```bash
students=("Ali Khan" "Mary Smith")
```

This creates two elements.

---

## Mistake 5: Expecting Output Automatically

This script:

```bash
#!/bin/bash

files=("f1.txt" "f2.txt")
```

does not display anything.

Creating a variable or an array does not automatically print it.

An output command such as `echo` or `printf` is needed to display values.

# Summary

An array allows several related values to be stored under one name.

Instead of this:

```bash
file1="f1.txt"
file2="f2.txt"
file3="f3.txt"
```

we can write:

```bash
files=("f1.txt" "f2.txt" "f3.txt")
```

The basic array syntax is:

```bash
array_name=("value1" "value2" "value3")
```

Important rules:

- Do not use spaces around `=`.
- Do not separate elements with commas.
- Use quotation marks for values containing spaces.
- Bash indexed arrays begin at index `0`.
- Creating an array does not automatically display it.

The next lesson will explain how to access individual array elements and display all elements.
