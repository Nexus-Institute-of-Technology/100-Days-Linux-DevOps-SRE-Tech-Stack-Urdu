# 1. Review: Creating an Array

An array stores multiple values under one variable name.

Example:

```bash
files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")
```

This array is named:

```text
files
```

It contains five elements:

```text
f1.txt
f2.txt
f3.txt
f4.txt
f5.txt
```

---

# 2. Understanding Array Indexes

Every element in a Bash indexed array has a position number called an **index**.

Bash array indexing begins at `0`.

For this array:

```bash
files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")
```

the indexes are:

| Index | Element |
|---:|---|
| `0` | `f1.txt` |
| `1` | `f2.txt` |
| `2` | `f3.txt` |
| `3` | `f4.txt` |
| `4` | `f5.txt` |

The first element is at index `0`, not index `1`.

---

## Important Rule

If an array contains `N` elements:

```text
First index = 0
Last index  = N - 1
```

For example, if an array contains five elements:

```text
Last index = 5 - 1
Last index = 4
```

If an array contains 100 elements:

```text
Last index = 100 - 1
Last index = 99
```

---

# 3. Syntax for Accessing One Array Element

The syntax is:

```bash
${array_name[index]}
```

Example:

```bash
echo "${files[0]}"
```

Output:

```text
f1.txt
```

---

## Syntax Breakdown

```bash
${files[0]}
```

| Part | Meaning |
|---|---|
| `$` | Requests the value |
| `{ }` | Encloses the array expression |
| `files` | Array name |
| `[0]` | Index of the required element |


Output:


```bash

```

Output:

```text
f3.txt
```

Access the fourth element:


```text
f4.txt
```


---

# 5. Why Curly Braces Are Important

The recommended syntax is:

```bash
"${files[0]}"
```

Do not write:

```bash
$files[0]
```

In Bash, `$files` by itself normally refers only to the first value of the array, while `[0]` may be treated as ordinary text.

Correct:

```bash
echo "${files[0]}"
```

Incorrect or misleading:

```bash
echo "$files[0]"
```

# 7. Using Array Elements with `touch`

The `touch` command:

- Creates an empty file if the file does not exist.
- Updates the file timestamp if the file already exists.

Create a script named:

```text
timestamp.sh
```

Add:

```bash
#!/bin/bash

files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")

touch "${files[0]}"
touch "${files[1]}"
touch "${files[2]}"
touch "${files[3]}"
touch "${files[4]}"
```

Make it executable:

```bash
chmod +x timestamp.sh
```

Run it:

```bash
./timestamp.sh
```

Verify the files:

```bash
ls -l f*.txt
```

Expected files:

```text
f1.txt
f2.txt
f3.txt
f4.txt
f5.txt
```

---

## What Happens the First Time?

The first time the script runs, the files do not yet exist.

Therefore, `touch` creates them.

---

## What Happens the Second Time?

Run the script again:

```bash
./timestamp.sh
```

The files already exist, so `touch` updates their modification timestamps.

Verify:

```bash
ls -l f*.txt
```

# 8. Displaying All Array Elements

To display every element in an array, use:

```bash
"${files[@]}"
```

Example:

```bash
echo "${files[@]}"
```

Output:

```text
f1.txt f2.txt f3.txt f4.txt f5.txt
```

---

## Using `*`

You may also see:

```bash
echo "${files[*]}"
```

This also displays all elements on one line:

```text
f1.txt f2.txt f3.txt f4.txt f5.txt
```

---

## `@` Versus `*`

For a simple `echo`, both may appear similar:

```bash
echo "${files[@]}"
echo "${files[*]}"
```

However, they behave differently when values contain spaces.

Consider:

```bash
students=("Ali Khan" "Mary Smith" "John Doe")
```

Using `@`:

```bash
for student in "${students[@]}"
do
    echo "$student"
done
```

Output:

```text
Ali Khan
Mary Smith
John Doe
```

Each array element remains separate.

For most Bash array processing, prefer:

```bash
"${array_name[@]}"
```

---

# 9. Counting Array Elements

To display the number of elements in an array, use:

```bash
${#array_name[@]}
```

Example:

```bash
echo "${#files[@]}"
```

Output:

```text
5
```

---

## Syntax Breakdown

```bash
${#files[@]}
```

| Part | Meaning |
|---|---|
| `$` | Requests a value |
| `{ }` | Encloses the expression |
| `#` | Counts elements |
| `files` | Array name |
| `[@]` | Refers to all array elements |

---

## Example with a Message

```bash
echo "Number of elements: ${#files[@]}"
```

Output:

```text
Number of elements: 5
```

# 11. Changing an Existing Array Element

An array element can be changed by assigning a new value to its index.

Syntax:

```bash
array_name[index]="new_value"
```

Example:

```bash
files[0]="a.txt"
```

This changes the first element.

Before:

```text
Index 0 = f1.txt
```

After:

```text
Index 0 = a.txt
```

---

## Example Script

```bash
#!/bin/bash

files=("f1.txt" "f2.txt")

echo "Before: ${files[@]}"

files[0]="a.txt"

echo "After:  ${files[@]}"
```

Output:

```text
Before: f1.txt f2.txt
After:  a.txt f2.txt
```

---

## Change the Second Element

```bash
files[1]="b.txt"
```

Complete example:

```bash
#!/bin/bash

files=("f1.txt" "f2.txt")

echo "Original array: ${files[@]}"

files[0]="a.txt"
files[1]="b.txt"

echo "Updated array:  ${files[@]}"
```

Output:

```text
Original array: f1.txt f2.txt
Updated array:  a.txt b.txt
```

---

# 12. Important Assignment Rule

Do not use `$` when assigning a value.

Correct:

```bash
files[0]="a.txt"
```

Incorrect:

```bash
$files[0]="a.txt"
```

Use `$` only when retrieving or displaying a value:

```bash
echo "${files[0]}"
```

# 15. Improved `timestamp.sh`

The manual version is:

```bash
#!/bin/bash

files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")

touch "${files[0]}"
touch "${files[1]}"
touch "${files[2]}"
touch "${files[3]}"
touch "${files[4]}"
```

This works, but it repeats the `touch` command.

A better version uses a loop:

```bash
#!/bin/bash

files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")

for file in "${files[@]}"
do
    touch "$file"
done
```

This version works even if more elements are later added to the array.

---

## Loop Explanation

```bash
for file in "${files[@]}"
```

Reads each array element one at a time and stores it temporarily in `file`.

```bash
do
```

Begins the repeated commands.

```bash
touch "$file"
```

Creates or updates the current file.

```bash
done
```

Ends the loop.

---

# 16. Accessing the Last Element Dynamically

Instead of manually using index `4`, Bash can calculate the last element.

One method is:

```bash
last_index=$((${#files[@]} - 1))
```

Then access it:

```bash
echo "${files[$last_index]}"
```

Complete example:

```bash
#!/bin/bash

files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")

last_index=$((${#files[@]} - 1))

echo "Last index: $last_index"
echo "Last element: ${files[$last_index]}"
```

Output:

```text
Last index: 4
Last element: f5.txt
```

---

## Bash Shortcut for the Last Element

Modern Bash also supports:

```bash
echo "${files[-1]}"
```

Output:

```text
f5.txt
```

For beginner exercises, using `N - 1` helps explain array indexing clearly.

# 17. Accessing Array Index Numbers

To display all index numbers in an array, use:

```bash
echo "${!files[@]}"
```

Output:

```text
0 1 2 3 4
```

---

## Example Script

```bash
#!/bin/bash

files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")

echo "Indexes:  ${!files[@]}"
echo "Elements: ${files[@]}"
```

Output:

```text
Indexes:  0 1 2 3 4
Elements: f1.txt f2.txt f3.txt f4.txt f5.txt
```

---

# 18. Loop Through Indexes and Values

```bash
#!/bin/bash

files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")

for index in "${!files[@]}"
do
    echo "Index $index contains ${files[$index]}"
done
```

Output:

```text
Index 0 contains f1.txt
Index 1 contains f2.txt
Index 2 contains f3.txt
Index 3 contains f4.txt
Index 4 contains f5.txt
```

This is useful when both the index and value are needed.

# 19. Common Mistakes

## Mistake 1: Starting at Index 1

Incorrect assumption:

```text
First element is at index 1
```

Correct rule:

```text
First element is at index 0
```

---

## Mistake 2: Forgetting Curly Braces

Incorrect:

```bash
echo "$files[2]"
```

Correct:

```bash
echo "${files[2]}"
```

---

## Mistake 3: Using `$` During Assignment

Incorrect:

```bash
$files[0]="a.txt"
```

Correct:

```bash
files[0]="a.txt"
```

---

## Mistake 4: Using the Wrong Index

For an array with five elements, this is outside the normal range:

```bash
echo "${files[5]}"
```

Valid indexes are:

```text
0 1 2 3 4
```

---

## Mistake 5: Using an Unquoted Array Expansion

Less safe:

```bash
for item in ${files[@]}
```

Preferred:

```bash
for item in "${files[@]}"
```

The quoted version preserves elements containing spaces.

---

## Mistake 6: Confusing Element Count with Last Index

For five elements:

```text
Element count = 5
Last index    = 4
```

These are not the same value.

# 24. Final Challenge: Array Report

Create a script named:

```text
array_report.sh
```

The script must:

1. Create an array containing five Linux directories.
2. Display the first directory.
3. Display the last directory.
4. Display all directories.
5. Display all indexes.
6. Display the total number of elements.
7. Display every index and its corresponding value.

Suggested array:

```bash
directories=("/etc" "/var" "/home" "/tmp" "/usr")
```

---

## Final Challenge Solution

```bash
#!/bin/bash

directories=("/etc" "/var" "/home" "/tmp" "/usr")

last_index=$((${#directories[@]} - 1))

echo "First directory: ${directories[0]}"
echo "Last directory: ${directories[$last_index]}"
echo "All directories: ${directories[@]}"
echo "Indexes: ${!directories[@]}"
echo "Number of elements: ${#directories[@]}"

echo
echo "Index and value report:"

for index in "${!directories[@]}"
do
    echo "Index $index = ${directories[$index]}"
done
```

Expected output:

```text
First directory: /etc
Last directory: /usr
All directories: /etc /var /home /tmp /usr
Indexes: 0 1 2 3 4
Number of elements: 5

Index and value report:
Index 0 = /etc
Index 1 = /var
Index 2 = /home
Index 3 = /tmp
Index 4 = /usr
```

# Summary

A Bash indexed array begins at index `0`.

For this array:

```bash
files=("f1.txt" "f2.txt" "f3.txt" "f4.txt" "f5.txt")
```

the indexes are:

```text
0 1 2 3 4
```

Access one element:

```bash
echo "${files[0]}"
```

Display all elements:

```bash
echo "${files[@]}"
```

Count the elements:

```bash
echo "${#files[@]}"
```

Display all indexes:

```bash
echo "${!files[@]}"
```

Change an element:

```bash
files[0]="a.txt"
```
