# Module 12: Bash Arrays — Appending to an Array

## Lesson Overview

In the previous lesson, we learned how to:

- Access individual array elements.
- Display all elements in an array.
- Count the number of elements.
- Change the value stored at a specific index.

In this lesson, we will learn how to **append** new elements to an existing Bash array.

To append means:

> Add a new element to the end of an array.

---

## Learning Objectives

By the end of this lesson, students will be able to:

- Explain what appending means.
- Add one new element to the end of an array.
- Add multiple elements at the same time.
- Display an array before and after appending.
- Count the number of elements before and after appending.
- Use quotation marks correctly when an element contains spaces.
- Avoid common array-append syntax mistakes.
- Build a simple script that grows an array.

---

## Review: Creating an Array

An array stores several values under one variable name.

Example:

```bash
distros=("Ubuntu" "Red Hat" "Fedora")
```

The array is named:

```text
distros
```

It contains three elements:

| Index | Element |
|---:|---|
| `0` | `Ubuntu` |
| `1` | `Red Hat` |
| `2` | `Fedora` |

Display all elements:

```bash
echo "${distros[@]}"
```

Output:

```text
Ubuntu Red Hat Fedora
```

Count the elements:

```bash
echo "${#distros[@]}"
```

Output:

```text
3
```

---

# 1. What Does Append Mean?

To **append** means to add something to the end.

Suppose we have:

```bash
distros=("Ubuntu" "Red Hat" "Fedora")
```

After appending `Kali Linux`, the array becomes:

```text
Ubuntu Red Hat Fedora Kali Linux
```

The original three elements remain unchanged. The new value is added at the next available index.

Before appending:

| Index | Element |
|---:|---|
| `0` | `Ubuntu` |
| `1` | `Red Hat` |
| `2` | `Fedora` |

After appending:

| Index | Element |
|---:|---|
| `0` | `Ubuntu` |
| `1` | `Red Hat` |
| `2` | `Fedora` |
| `3` | `Kali Linux` |

---

# 2. Syntax for Appending One Element

The syntax is:

```bash
array_name+=("new element")
```

Example:

```bash
distros+=("Kali Linux")
```

---

## Syntax Breakdown

```bash
distros+=("Kali Linux")
```

| Part | Meaning |
|---|---|
| `distros` | Name of the existing array |
| `+=` | Add to the current array |
| `(` and `)` | Hold the new array element |
| `"Kali Linux"` | New value being appended |

The `+=` operator means:

> Keep the current contents and add the new value.

---

# 3. Important Spacing Rule

Do not put spaces around `+=`.

Correct:

```bash
distros+=("Kali Linux")
```

Incorrect:

```bash
distros += ("Kali Linux")
```

The incorrect version causes Bash to interpret `distros` as a command.

---

# 4. Basic Append Example

```bash
#!/bin/bash

distros=("Ubuntu" "Red Hat" "Fedora")

echo "Before appending:"
echo "${distros[@]}"

distros+=("Kali Linux")

echo
echo "After appending:"
echo "${distros[@]}"
```

Expected output:

```text
Before appending:
Ubuntu Red Hat Fedora

After appending:
Ubuntu Red Hat Fedora Kali Linux
```

# 6. Display the Number of Elements Before and After

We can count array elements using:

```bash
${#array_name[@]}
```

Example:

```bash
#!/bin/bash

distros=("Ubuntu" "CentOS" "Fedora")

echo "Before appending:"
echo "Elements: ${distros[@]}"
echo "Count: ${#distros[@]}"

distros+=("Kali Linux")

echo
echo "After appending:"
echo "Elements: ${distros[@]}"
echo "Count: ${#distros[@]}"
```

Expected output:

```text
Before appending:
Elements: Ubuntu CentOS Fedora
Count: 3

After appending:
Elements: Ubuntu CentOS Fedora Kali Linux
Count: 4
```

---

# 7. Appending Multiple Elements

You can append more than one element at the same time.

Syntax:

```bash
array_name+=("value1" "value2" "value3")
```

Example:

```bash
distros+=("Debian" "Rocky Linux" "AlmaLinux")
```

Complete example:

```bash
#!/bin/bash

distros=("Ubuntu" "Fedora")

echo "Before:"
echo "${distros[@]}"

distros+=("Debian" "Rocky Linux" "AlmaLinux")

echo
echo "After:"
echo "${distros[@]}"
```

Expected output:

```text
Before:
Ubuntu Fedora

After:
Ubuntu Fedora Debian Rocky Linux AlmaLinux
```

The array now contains five elements.

---

# 8. Quoting Elements That Contain Spaces

Use quotation marks when an element contains spaces.

Correct:

```bash
distros+=("Kali Linux")
```

This adds one element:

```text
Kali Linux
```

Incorrect:

```bash
distros+=(Kali Linux)
```

This adds two separate elements:

```text
Kali
Linux
```

---

## Demonstration

```bash
#!/bin/bash

distros=("Ubuntu")

distros+=(Kali Linux)

echo "Count: ${#distros[@]}"
echo "Elements: ${distros[@]}"
```

Output:

```text
Count: 3
Elements: Ubuntu Kali Linux
```

Bash treats `Kali` and `Linux` as separate elements.

The correct version is:

```bash
distros+=("Kali Linux")
```

Then the output becomes:

```text
Count: 2
Elements: Ubuntu Kali Linux
```

Although the display looks similar, the array contains only two elements:

| Index | Element |
|---:|---|
| `0` | `Ubuntu` |
| `1` | `Kali Linux` |

---

# 9. Appending Values Stored in Variables

A value can be stored in a variable before being appended.

Example:

```bash
new_distro="Kali Linux"

distros+=("$new_distro")
```

Complete script:

```bash
#!/bin/bash

distros=("Ubuntu" "Fedora")
new_distro="Kali Linux"

distros+=("$new_distro")

echo "${distros[@]}"
```

Output:

```text
Ubuntu Fedora Kali Linux
```

Always quote the variable:

```bash
"$new_distro"
```

This preserves spaces inside the value.

# 10. Asking the User for a New Element

We can use `read` to ask the user for a value.

```bash
#!/bin/bash

distros=("Ubuntu" "Fedora" "Debian")

echo "Current distributions:"
echo "${distros[@]}"

read -r -p "Enter another Linux distribution: " new_distro

distros+=("$new_distro")

echo
echo "Updated distributions:"
echo "${distros[@]}"
```

Example interaction:

```text
Current distributions:
Ubuntu Fedora Debian
Enter another Linux distribution: Rocky Linux

Updated distributions:
Ubuntu Fedora Debian Rocky Linux
```

---

## Explanation

```bash
read -r -p "Enter another Linux distribution: " new_distro
```

Stores the user's input in the variable:

```text
new_distro
```

Then:

```bash
distros+=("$new_distro")
```

appends that value to the array.

---

# 11. Validate Empty Input

The user may press `Enter` without typing anything.

We can prevent an empty value from being appended.

```bash
#!/bin/bash

distros=("Ubuntu" "Fedora" "Debian")

read -r -p "Enter another Linux distribution: " new_distro

if [[ -z "$new_distro" ]]; then
    echo "Error: No distribution was entered."
    exit 1
fi

distros+=("$new_distro")

echo "Updated array:"
echo "${distros[@]}"
```

---

## Explanation

```bash
if [[ -z "$new_distro" ]]; then
```

checks whether the variable is empty.

```bash
exit 1
```

stops the script with an error status.

---

# 12. Append Several User Entries

The following script asks the user to enter three new distributions.

```bash
#!/bin/bash

distros=("Ubuntu" "Fedora")

read -r -p "Enter the first new distribution: " distro1
read -r -p "Enter the second new distribution: " distro2
read -r -p "Enter the third new distribution: " distro3

distros+=("$distro1" "$distro2" "$distro3")

echo
echo "Complete array:"
echo "${distros[@]}"
```

Example:

```text
Enter the first new distribution: Debian
Enter the second new distribution: Rocky Linux
Enter the third new distribution: Kali Linux

Complete array:
Ubuntu Fedora Debian Rocky Linux Kali Linux
```

---

# 13. Appending Inside a Loop

A loop can repeatedly ask the user for new values.

```bash
#!/bin/bash

distros=("Ubuntu" "Fedora")

for number in 1 2 3
do
    read -r -p "Enter distribution number $number: " new_distro
    distros+=("$new_distro")
done

echo
echo "Final array:"
echo "${distros[@]}"
```

---

## Explanation

```bash
for number in 1 2 3
```

runs the loop three times.

Each time:

```bash
read -r -p "Enter distribution number $number: " new_distro
```

asks for a new value.

Then:

```bash
distros+=("$new_distro")
```

adds the value to the end of the array.

---

# 14. Display the New Element's Index

Before appending, the array length gives us the next available index.

Example:

```bash
#!/bin/bash

distros=("Ubuntu" "Fedora" "Debian")

next_index=${#distros[@]}

echo "The next available index is: $next_index"

distros+=("Kali Linux")

echo "New element: ${distros[$next_index]}"
```

Output:

```text
The next available index is: 3
New element: Kali Linux
```

Because the original array had three elements, the new element was placed at index `3`.

---

# 15. Appending Versus Replacing

These two operations are different.

## Appending

```bash
distros+=("Kali Linux")
```

Adds a new value to the end.

Before:

```text
Ubuntu Fedora Debian
```

After:

```text
Ubuntu Fedora Debian Kali Linux
```

---

## Replacing

```bash
distros[1]="Kali Linux"
```

Changes the value at index `1`.

Before:

```text
Ubuntu Fedora Debian
```

After:

```text
Ubuntu Kali Linux Debian
```

The number of elements does not change when replacing an existing element.

---

# 16. Appending to an Empty Array

You can create an empty array:

```bash
distros=()
```

Then append values:

```bash
distros+=("Ubuntu")
distros+=("Fedora")
distros+=("Debian")
```

Complete example:

```bash
#!/bin/bash

distros=()

distros+=("Ubuntu")
distros+=("Fedora")
distros+=("Debian")

echo "Elements: ${distros[@]}"
echo "Count: ${#distros[@]}"
```

Output:

```text
Elements: Ubuntu Fedora Debian
Count: 3
```

# 17. Building an Array from User Input

```bash
#!/bin/bash

distros=()

read -r -p "Enter the first distribution: " first
distros+=("$first")

read -r -p "Enter the second distribution: " second
distros+=("$second")

read -r -p "Enter the third distribution: " third
```

This demonstrates how an array can grow one element at a time.

# 19. Why Use `printf`?

This command:

```bash
echo "${distros[@]}"
```

prints all elements on one line.

This command:

```bash
printf '%s\n' "${distros[@]}"
```

prints one element per line.

Example:

```bash
printf '%s\n' "${distros[@]}"
```

Output:

```text
Ubuntu
Fedora
Debian
Kali Linux
```

This is often easier to read.

# 20. Common Mistakes

## Mistake 1: Spaces Around `+=`

Incorrect:

```bash
distros += ("Kali Linux")
```

Correct:

```bash
distros+=("Kali Linux")
```

---

## Mistake 2: Forgetting Parentheses

Incorrect:

```bash
distros+="Kali Linux"
```

For indexed arrays, use:

```bash
distros+=("Kali Linux")
```

The parentheses clearly indicate an array append operation.

---

## Mistake 3: Forgetting Quotes

Incorrect:

```bash
distros+=(Kali Linux)
```

This appends two elements.

Correct:

```bash
distros+=("Kali Linux")
```

This appends one element.

---

## Mistake 4: Using `$` on the Left Side

Incorrect:

```bash
$distros+=("Kali Linux")
```

Correct:

```bash
distros+=("Kali Linux")
```

Do not use `$` when assigning or appending.

Use `$` when reading the value:

```bash
echo "${distros[@]}"
```

---

## Mistake 5: Using Commas

Incorrect:

```bash
distros+=("Debian", "Kali Linux")
```

Bash arrays do not use commas.

Correct:

```bash
distros+=("Debian" "Kali Linux")
```

---

## Mistake 6: Appending an Empty Value

This may add an empty element:

```bash
new_distro=""
distros+=("$new_distro")
```

Validate the input first:

```bash
if [[ -n "$new_distro" ]]; then
    distros+=("$new_distro")
fi
```

The `-n` test means the value is not empty.

# 24. Final Challenge: Interactive Distribution Builder

Create a script named:

```text
distro_builder.sh
```

The script must:

1. Begin with an empty array.
2. Ask the user how many distributions they want to enter.
3. Repeatedly ask for a distribution name.
4. Append each entry to the array.
5. Display every distribution.
6. Display the total number of elements.

---

## Final Challenge Solution

```bash
#!/bin/bash

distros=()

read -r -p "How many distributions would you like to enter? " total

if [[ ! "$total" =~ ^[1-9][0-9]*$ ]]; then
    echo "Error: Enter a positive whole number."
    exit 1
fi

for ((count=1; count<=total; count++))
do
    read -r -p "Enter distribution $count: " new_distro

    if [[ -z "$new_distro" ]]; then
        echo "Error: Distribution name cannot be empty."
        exit 1
    fi

    distros+=("$new_distro")
done

echo
echo "Linux distributions entered:"
printf '%s\n' "${distros[@]}"

echo
echo "Total distributions: ${#distros[@]}"
```

# Summary

To append a new element to a Bash array, use:

```bash
array_name+=("new value")
```

Example:

```bash
distros=("Ubuntu" "Fedora" "Debian")
distros+=("Kali Linux")
```

Display the updated array:

```bash
echo "${distros[@]}"
```

Output:

```text
Ubuntu Fedora Debian Kali Linux
```

Append multiple elements:

```bash
distros+=("Rocky Linux" "AlmaLinux")
```

Important rules:

- Do not put spaces around `+=`.
- Use parentheses.
- Quote values that contain spaces.
- Do not place `$` before the array name when appending.
- Use `"${array[@]}"` when displaying or processing all elements.
- Use `"${#array[@]}"` to count the elements.

The next lesson will explain how to delete or remove elements from a Bash array.
