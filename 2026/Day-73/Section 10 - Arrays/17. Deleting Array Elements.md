# Module 12: Bash Arrays — Deleting an Element from an Array

## Lesson Overview

In the previous lesson, we learned how to append new elements to an existing Bash array.

In this lesson, we will learn how to:

- Remove one element from an array.
- Remove an element by its index.
- Delete an entire array.
- Delete a normal Bash variable.
- Verify the array before and after deletion.
- Understand what happens to array indexes after an element is removed.

The main command used in this lesson is:

```bash
unset
```

---

## Learning Objectives

By the end of this lesson, students will be able to:

- Explain what the `unset` command does.
- Delete one array element using its index.
- Delete an entire array.
- Delete a normal Bash variable.
- Display an array before and after removing an element.
- Understand that Bash does not automatically renumber remaining indexes.
- Check whether a variable or array still exists.
- Build a simple script that removes selected array values.

---

# 1. Review: Creating an Array

An array stores multiple values under one variable name.

Example:

```bash
nums=(1 2 3 4 5)
```

The array is named:

```text
nums
```

It contains five elements:

| Index | Element |
|---:|---:|
| `0` | `1` |
| `1` | `2` |
| `2` | `3` |
| `3` | `4` |
| `4` | `5` |

Remember:

> Bash indexed arrays begin at index `0`.

---

# 2. What Does `unset` Do?

The `unset` command removes a variable or an array element from the current shell.

Basic syntax:

```bash
unset variable_name
```

Examples:

```bash
unset car
```

```bash
unset 'nums[2]'
```

```bash
unset nums
```

The meaning depends on what is placed after `unset`.

# 3. Deleting a Normal Variable

Create a variable:

```bash
car="Maserati"
```

Display it:

```bash
echo "$car"
```

Output:

```text
Maserati
```

Delete the variable:

```bash
unset car
```

Try to display it again:

```bash
echo "$car"
```

No value is displayed because the variable no longer exists.

---

## Complete Example

```bash
#!/bin/bash

car="Maserati"

echo "Before unset: $car"

unset car

echo "After unset: $car"
```

Expected output:

```text
Before unset: Maserati
After unset:
```

The second line has no value after the colon.

# 4. Deleting One Array Element

To delete one array element, use:

```bash
unset 'array_name[index]'
```

Example:

```bash
unset 'nums[2]'
```

This removes the element at index `2`.

Given:

```bash
nums=(1 2 3 4 5)
```

the value at index `2` is:

```text
3
```

Therefore:

```bash
unset 'nums[2]'
```

removes the number `3`.

---

## Before Deletion

```text
Index 0 = 1
Index 1 = 2
Index 2 = 3
Index 3 = 4
Index 4 = 5
```

## After Deletion

```text
Index 0 = 1
Index 1 = 2
Index 3 = 4
Index 4 = 5
```

Notice that index `2` is now missing.

Bash does not automatically change index `3` to index `2`.

---

# 5. Why Quote `array[index]`?

The recommended syntax is:

```bash
unset 'nums[2]'
```

You may also see:

```bash
unset nums[2]
```

However, square brackets may be interpreted by the shell as filename-matching characters.

Quoting the array reference is safer:

```bash
unset 'nums[2]'
```

You may also use:

```bash
unset "nums[2]"
```

For this lesson, we will use:

```bash
unset 'nums[2]'
```

# 7. Deleting the Third Element

Students often confuse the third element with index `3`.

Remember:

| Position | Index |
|---:|---:|
| First element | `0` |
| Second element | `1` |
| Third element | `2` |
| Fourth element | `3` |
| Fifth element | `4` |

To delete the third element:

```bash
unset 'nums[2]'
```

Example:

```bash
nums=(1 2 3 4 5)

unset 'nums[2]'

echo "${nums[@]}"
```

Output:

```text
1 2 4 5
```

# 8. Displaying Indexes Before and After Deletion

Use:

```bash
echo "${!nums[@]}"
```

to display all current indexes.

Example:

```bash
#!/bin/bash

nums=(1 2 3 4 5)

echo "Before deletion:"
echo "Indexes: ${!nums[@]}"
echo "Values:  ${nums[@]}"

unset 'nums[2]'

echo
echo "After deletion:"
echo "Indexes: ${!nums[@]}"
echo "Values:  ${nums[@]}"
```

Expected output:

```text
Before deletion:
Indexes: 0 1 2 3 4
Values:  1 2 3 4 5

After deletion:
Indexes: 0 1 3 4
Values:  1 2 4 5
```

This proves that Bash leaves an index gap.

# 12. Check Whether an Array Still Exists

Use `declare -p`:

```bash
declare -p nums
```

If the array exists, Bash displays its declaration.

Example:

```text
declare -a nums=([0]="1" [1]="2" [2]="3")
```

After:

```bash
unset nums
```

run:

```bash
declare -p nums
```

Bash may display an error similar to:

```text
bash: declare: nums: not found
```

---

## Suppress the Error

```bash
declare -p nums &>/dev/null
```

Use it in a condition:

```bash
if declare -p nums &>/dev/null; then
    echo "The nums array exists."
else
    echo "The nums array does not exist."
fi
```

# 14. Removing the Last Element

A simple method is to calculate the last index:

```bash
last_index=$((${#nums[@]} - 1))
```

Then remove it:

```bash
unset "nums[$last_index]"
```

Complete example:

```bash
#!/bin/bash

nums=(1 2 3 4 5)

last_index=$((${#nums[@]} - 1))

echo "Last index: $last_index"
echo "Last value: ${nums[$last_index]}"

unset "nums[$last_index]"

echo "Updated array: ${nums[@]}"
```

Expected output:

```text
Last index: 4
Last value: 5
Updated array: 1 2 3 4
```

---

## Important Note About Sparse Arrays

The calculation:

```bash
$((${#nums[@]} - 1))
```

works correctly when the indexes are continuous:

```text
0 1 2 3 4
```

If elements have already been deleted, the array may contain gaps.

For example:

```text
0 1 3 4
```

In such cases, the number of elements is `4`, but the highest index is still `4`.

A more reliable method for sparse arrays is covered later in this lesson.

# 15. Find the Highest Existing Index

Use the current indexes:

```bash
indexes=("${!nums[@]}")
last_index="${indexes[-1]}"
```

Example:

```bash
#!/bin/bash

nums=(1 2 3 4 5)

unset 'nums[2]'

indexes=("${!nums[@]}")
last_index="${indexes[-1]}"

echo "Current indexes: ${!nums[@]}"
echo "Highest index: $last_index"
echo "Last value: ${nums[$last_index]}"
```

Expected output:

```text
Current indexes: 0 1 3 4
Highest index: 4
Last value: 5
```

# 16. Remove an Element Selected by the User

```bash
#!/bin/bash

fruits=("apple" "banana" "orange" "mango")

echo "Available indexes and values:"

for index in "${!fruits[@]}"
do
    echo "Index $index: ${fruits[$index]}"
done

read -r -p "Enter the index to delete: " delete_index

if [[ ! "$delete_index" =~ ^[0-9]+$ ]]; then
    echo "Error: Enter a valid non-negative index."
    exit 1
fi

if [[ ! -v "fruits[$delete_index]" ]]; then
    echo "Error: Index $delete_index does not exist."
    exit 1
fi

unset "fruits[$delete_index]"

echo
echo "Updated array:"
echo "${fruits[@]}"
```

Enter the index to delete: 1

# 17. Remove an Element by Value

Sometimes the user knows the value, but not the index.

Example:

```bash
#!/bin/bash

fruits=("apple" "banana" "orange" "mango")

read -r -p "Enter the fruit to remove: " target

found=false

for index in "${!fruits[@]}"
do
    if [[ "${fruits[$index]}" == "$target" ]]; then
        unset "fruits[$index]"
        found=true
        break
    fi
done

if [[ "$found" == true ]]; then
    echo "Removed: $target"
    echo "Updated array: ${fruits[@]}"
else
    echo "The value '$target' was not found."
fi
```

---

# 18. Delete Every Matching Value

The previous example removes only the first match.

To remove every matching value:

```bash
#!/bin/bash

items=("red" "blue" "red" "green" "red")

target="red"

for index in "${!items[@]}"
do
    if [[ "${items[$index]}" == "$target" ]]; then
        unset "items[$index]"
    fi
done

echo "${items[@]}"
```

Output:

```text
blue green
```

# 19. Reindexing an Array After Deletion

After deleting an element, Bash may leave a gap in the indexes.

Example:

```bash
nums=(1 2 3 4 5)

unset 'nums[2]'
```

Indexes become:

```text
0 1 3 4
```

To rebuild the array with continuous indexes:

```bash
nums=("${nums[@]}")
```

---

## Example

```bash
#!/bin/bash

nums=(1 2 3 4 5)

unset 'nums[2]'

echo "Before reindexing:"
echo "Indexes: ${!nums[@]}"
echo "Values:  ${nums[@]}"

nums=("${nums[@]}")

echo
echo "After reindexing:"
echo "Indexes: ${!nums[@]}"
echo "Values:  ${nums[@]}"
```

Expected output:

```text
Before reindexing:
Indexes: 0 1 3 4
Values:  1 2 4 5

After reindexing:
Indexes: 0 1 2 3
Values:  1 2 4 5
```

---

# 20. Deleting Versus Replacing

These operations are different.

## Delete an Element

```bash
unset 'nums[2]'
```

The element is removed, and the element count decreases.

---

## Replace an Element

```bash
nums[2]=99
```

The index remains, but its value changes.

Example:

```bash
nums=(1 2 3 4 5)

nums[2]=99

echo "${nums[@]}"
```

Output:

```text
1 2 99 4 5
```

---

# 21. Emptying an Array Without Removing Its Name

This removes all elements but creates an empty array:

```bash
nums=()
```

Example:

```bash
nums=(1 2 3 4 5)

nums=()

echo "Count: ${#nums[@]}"
```

Output:

```text
Count: 0
```

---

## Difference Between `nums=()` and `unset nums`

### Empty Array

```bash
nums=()
```

The variable still exists as an empty array.

### Deleted Array

```bash
unset nums
```

The variable itself is removed.

# 23. Common Mistakes

## Mistake 1: Confusing Position and Index

Incorrect assumption:

```text
The third element is at index 3.
```

Correct:

```text
The third element is at index 2.
```

---

## Mistake 2: Forgetting the Index

```bash
unset nums
```

This deletes the entire array.

To delete only one element:

```bash
unset 'nums[2]'
```

---

## Mistake 3: Expecting Automatic Reindexing

After:

```bash
unset 'nums[2]'
```

Bash does not automatically convert:

```text
0 1 3 4
```

into:

```text
0 1 2 3
```

Reindex manually with:

```bash
nums=("${nums[@]}")
```

---

## Mistake 4: Using an Invalid Index

```bash
unset 'nums[20]'
```

If index `20` does not exist, Bash normally does not display an error. The array remains unchanged.

Check first:

```bash
if [[ -v 'nums[20]' ]]; then
    unset 'nums[20]'
fi
```

---

## Mistake 5: Using `$` on the Left Side

Incorrect:

```bash
unset '${nums[2]}'
```

This refers to the value, not the array location.

Correct:

```bash
unset 'nums[2]'
```

---

## Mistake 6: Forgetting Quotes

Less safe:

```bash
unset nums[2]
```

Preferred:

```bash
unset 'nums[2]'
```

Quoting prevents shell pattern expansion.

# 25. Student Challenge 1: Server Array

Create a script named:

```text
remove_server.sh
```

Use:

```bash
servers=("web01" "web02" "db01" "backup01")
```

The script must:

1. Display all indexes and server names.
2. Ask the user for an index.
3. Verify that the index exists.
4. Remove that server.
5. Display the updated array.

---

## Solution

```bash
#!/bin/bash

servers=("web01" "web02" "db01" "backup01")

echo "Current servers:"

for index in "${!servers[@]}"
do
    echo "Index $index: ${servers[$index]}"
done

read -r -p "Enter the server index to remove: " remove_index

if [[ ! "$remove_index" =~ ^[0-9]+$ ]]; then
    echo "Error: Enter a valid index."
    exit 1
fi

if [[ ! -v "servers[$remove_index]" ]]; then
    echo "Error: Index $remove_index does not exist."
    exit 1
fi

removed_server="${servers[$remove_index]}"

unset "servers[$remove_index]"

echo
echo "Removed server: $removed_server"
echo "Remaining servers: ${servers[@]}"
```

# Summary

To delete one element from a Bash array, use:

```bash
unset 'array_name[index]'
```

Example:

```bash
nums=(1 2 3 4 5)

unset 'nums[2]'
```

The updated array contains:

```text
1 2 4 5
```

To delete the entire array:

```bash
unset nums
```

To display the remaining indexes:

```bash
echo "${!nums[@]}"
```

To rebuild the array with continuous indexes:

```bash
nums=("${nums[@]}")
```

Important rules:

- Array indexing begins at `0`.
- The third element is stored at index `2`.
- `unset 'nums[2]'` removes one element.
- `unset nums` removes the entire array.
- Bash does not automatically reindex remaining elements.
- Quote the array reference passed to `unset`.
